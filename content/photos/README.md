# Handwriting photos

Put the photos here. They play in **filename order**.

| | |
|---|---|
| **Size** | **1200 × 1600 px**, portrait 3:4 |
| **Format** | JPEG (`.jpg`), or PNG/WebP |
| **File size** | under 1 MB each, 1.5 MB at most |
| **Names** | `01.jpg`, `02.jpg`, `03.jpg`, … |

- Photos are fitted to the screen without cropping, so other sizes still work. `npm run check` warns about anything that isn't 3:4 or is too large.
- Files whose names start with `_` are ignored. The `_placeholder-*.jpg` samples are used only while no real photos are here. Delete them once you add yours.
